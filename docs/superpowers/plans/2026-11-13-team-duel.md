# Ancien gros vs Ancien maigre Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter un duel d'équipes recalculé depuis les classements révélés, avec un onglet participant et un panneau d'affectation admin.

**Architecture:** Une colonne nullable `team` sur `participants` représente l'affectation courante. Un helper serveur construit les statistiques et la tendance à partir des seules révélations `ranking` `sent`; les deux API l'exposent sans cache.

**Tech Stack:** Flask, SQLite, JavaScript sans framework, CSS existant, pytest.

**Spec:** `docs/superpowers/specs/2026-11-13-ancien-gros-vs-ancien-maigre-design.md`

## Global Constraints

- Les seuls camps valides sont `ancien_gros`, `ancien_maigre` et `null`.
- Les statistiques lisent exclusivement les révélations `ranking` `sent`.
- La moyenne la plus basse gagne et toute mutation admin recalcule immédiatement le présent et l'historique.
- Aucune dépendance JavaScript ou graphique supplémentaire.
